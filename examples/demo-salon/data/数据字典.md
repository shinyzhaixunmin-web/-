# 数据字典

`tools/salon_metrics.py` 读取以下 CSV 文件（UTF-8 编码，第一行是表头）。把真实门店数据按这个格式从收银系统导出，就能直接计算经营基线。

> 本目录下的数据是**虚构的**，由 `gen_demo_data.py` 生成，只用于演示。

## customers.csv：顾客档案（必需）
| 字段 | 说明 | 示例 |
|---|---|---|
| customer_id | 顾客唯一编号 | C00123 |
| store | 首次到店的门店 | A店 |
| first_visit_date | 首次到店日期（YYYY-MM-DD）。数据开始之前就来过的老客，填真实的首次日期 | 2026-02-14 |
| channel | 获客渠道。老客没有记录时填"存量老客" | 团购平台 |

## visits.csv：到店服务记录（必需）
| 字段 | 说明 | 示例 |
|---|---|---|
| visit_id | 服务单号 | V000001 |
| date | 服务日期 | 2026-04-03 |
| store | 门店 | A店 |
| customer_id | 顾客编号 | C00123 |
| stylist | 技师 | A1 |
| service | 项目 | 护理 |
| amount | 服务金额，即**按服务消耗确认的收入** | 380 |
| pay_type | `现付` 或 `耗卡`（从储值中扣） | 耗卡 |
| booked_next | 离店时是否当场预约下次：`是` / `否` | 是 |
| complaint | 这次服务是否有投诉：`是` / `否` | 否 |

## card_sales.csv：办卡或储值记录（必需，没有就只放表头）
| 字段 | 说明 | 示例 |
|---|---|---|
| sale_id | 单号 | S00001 |
| date | 日期 | 2026-03-08 |
| store | 门店 | B店 |
| customer_id | 顾客编号 | C00456 |
| amount | 储值金额。这是**预收款，属于负债，不是收入** | 5000 |

## staff_events.csv：人员变动（可选）
| 字段 | 说明 | 示例 |
|---|---|---|
| date | 日期 | 2026-05-15 |
| store | 门店 | A店 |
| stylist | 技师 | A5 |
| event | `入职` 或 `离职` | 离职 |

## costs.csv：成本（可选；没有这个文件时，利润标注为"待补"）
| 字段 | 说明 | 示例 |
|---|---|---|
| month | 月份（YYYY-MM） | 2026-04 |
| store | 门店 | A店 |
| category | 成本类别，如房租、人工、物料 | 房租 |
| amount | 金额 | 30000 |

## 口径规则（脚本会自动执行）
- 收入只算 `visits.csv` 的 amount（按服务消耗确认）。办卡金额单独列出，**不相加**。
- 新客指 first_visit_date 落在数据期间内的顾客。
- 复购：首次到店后 N 天内（默认 60 天）有第二次到店。按首次到店月份把新客分组；**一组新客要等全部成员都满观察窗口后才计算**，没满的组显示到期日期。
