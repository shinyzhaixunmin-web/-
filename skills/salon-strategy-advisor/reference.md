# 沙龙战略咨询参考资料

> 标记说明：**【原模型】** 表示内容直接来自 `knowledge/shiny-ci-dbs-v1/core.md`；**【补充】** 表示美业通用做法，原模型中没有，使用时要根据门店实际情况确认口径。

## 1. 指标库

### 口径铁律【原模型】
- 收入、利润、现金分别看。**办卡（预收）和耗卡（服务消耗）不能相加成营业额。**
- 复购率必须固定顾客群和观察窗口。窗口还没到期的数据不下结论。
- 没有完整基线的指标，标注"待验证"。

### 按主题分类
| 主题 | 过程指标 | 结果指标 | 保护指标 |
|---|---|---|---|
| 等待与准时【原模型】 | 交接完成率、预约时长偏差 | 等待时间中位数、P90、准时开工比例 | 返工、投诉、员工加班、可接待量、顾客体验 |
| 新客留存【补充】 | 离店预约率、首次服务后回访完成率 | 固定新客群的 30、60、90 天复购率 | 客诉、强推感知、折扣依赖度（复购中使用折扣的占比） |
| 老客与会员【补充】 | 到期提醒完成率、会员回访完成率 | 耗卡率、会员流失率、老客到店频次 | 退卡、退款金额、投诉 |
| 客单与项目【补充】 | 咨询时方案确认率（需求、价格、方案三项都确认） | 客单价、项目结构占比 | 价格争议、退款、满意度 |
| 员工与产能【补充】 | 标准作业执行率、带教完成率 | 人均服务耗卡额（口径要统一）、工位利用率 | 加班时长、员工流失、返工率 |
| 服务质量【补充】 | 关键节点确认率、异常求助次数（求助次数上升未必是坏事） | 返工率、投诉率、差评率 | 服务时长是否被不当压缩 |
| 现金与利润【补充】 | 预收余额台账每周更新 | 月度经营利润、经营现金流 | 预收余额与耗卡能力是否匹配（预收的是负债） |

每个指标都要写清：**定义、分子与分母、数据来源、统计周期、负责人**。

## 2. 常见问题的根因候选【补充】
这些只是假设起点，必须到现场逐项核验（原则 1）。

| 现象 | 根因候选（要验证，不能直接采信） |
|---|---|
| 顾客等待久 | 预约时长设置不准、关键工位冲突、前一道工序超时、交接不清【原模型】；此外还有顾客迟到，要和门店延误分开统计 |
| 新客不回头 | 离店时没有约定下次时间、引流客群意向低、首次体验因技师而异、没有回访 |
| 客单价低 | 咨询流程没有需求诊断、项目组合不清、技师不会介绍、价格体系混乱 |
| 员工流失 | 排班与收入不稳定、带教缺失、晋升路径不清、负荷过重 |
| 投诉增加 | 关键节点没有确认（价格、效果预期）、标准缺失或未培训、高峰期负荷过重 |
| 业绩波动大 | 依赖办卡冲业绩、季节性、个别明星技师的去留 |

## 4. 门槛③"跨店复现"的默认标准【补充，待用户确认】
原模型没有给出量化标准。在用户确认之前，默认使用以下标准：
- 至少**1 家**非标杆店**独立**执行，即不由标杆店的原班人员代为操作
- 执行时间跨过**一个完整观察周期**（复购类指标按对应窗口计算）
- 结果指标方向与标杆店一致，保护指标没有恶化
- 这家店有明确的负责人，能够自己带教新员工

## 5. 90 天试点节奏【原模型】
| 阶段 | 天数 | 要做的事 | 阶段产出 |
|---|---|---|---|
| 基线 | 1–30 | 统一口径，现场观察，验证根因 | 单店基线、问题卡的前半部分 |
| 试验 | 31–60 | 小范围试验，边做边修正 | 试验记录、指标周报 |
| 持续与复制 | 61–90 | 检查持续性，尝试在第二家店复现 | 复盘结论、标准草案、复制计划 |

慢指标（如复购）要按完整窗口延后判断。
