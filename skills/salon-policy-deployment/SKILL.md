# 方针展开（丹纳赫 DBS · 聚焦与配置）

> 知识来源：`knowledge/shiny-ci-dbs-v1/core.md`（模型 2 集团增长循环、模型 3 第 1–2 层）
> 战略地图模板与指标库：`../salon-strategy-advisor/reference.md`（第 1 节、3.1 节）

**核心纪律：方针展开是为了聚焦，不是把 KPI 层层摊派。** 突破目标最多 3 个，其余事项归入日常经营。

## 流程
1. **看基线**：先要一份当前的经营基线（收入按耗卡确认、办卡预收单列；利润；现金；新客；复购；员工流失）。没有基线时，**第一个突破目标就是"建立统一口径的经营基线"**，其余目标标注"待基线后确认数值"。
2. **定位与取舍**（第 1 层）：用四句话回答：
   - 服务谁？
   - 解决他们的什么需求？
   - 为什么选我们？
   - **暂时不做什么？**（至少写 1 条）
3. **找突破点**：列出候选问题或机会，按以下标准筛选：
   - 对顾客价值和经营结果影响大
   - 是当前的瓶颈，解决它其他问题会跟着缓解
   - 本阶段有资源做成
   - 与定位一致
   最后只留 1–3 个。其余的写进"本期不做（原因）"。
4. **配置资源**：每个突破目标都要写明：负责人（一个人）、投入的资源（人、钱、时间）、期限、衡量方式（结果指标 + 保护指标）。**没有负责人或没有资源的目标，不算目标。**
5. **拆到门店**：每个目标落到哪家店试点、先做哪件事。试点店按单店改善闭环推进，可以用 `salon-kaizen-card` 开问题卡。
6. **定检查节奏**：每月看过程指标，每季度看结果，决定继续、调整或把资源挪给别的目标。
7. **写再配置规则**：年中出现什么信号就追加投入、收缩或退出（例如结果指标连续两个季度没有改善，保护指标恶化）。

## 输出格式
```
# <年度/季度> 方针展开
## 定位与取舍
服务谁 / 解决什么 / 为什么选我们 / 暂时不做什么
## 突破目标（≤3）
| 目标 | 负责人 | 资源 | 期限 | 结果指标 | 保护指标 | 试点门店 |
## 本期不做（原因）
## 检查节奏：月度 / 季度
## 再配置规则
## 待基线确认的数值
```

## 反模式
- ❌ 十几个目标平均用力 → ✅ 1–3 个突破目标，其余归入日常经营
- ❌ 把"营业额（含办卡）增长 X%"当目标 → ✅ 收入、利润、现金分开定，储值属于预收
- ❌ 没有基线就定具体数字 → ✅ 先把建立基线作为第一个目标
- ❌ 目标写成口号（如"提升服务品质"） → ✅ 可衡量，有负责人和期限
